## Upload to GitHub
1. Create a GitHub repository.
2. Upload `index.html`.
3. Commit to the `main` branch.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select `main` and `/root`.
7. Save.

The product photography currently uses remote Unsplash image URLs. For a production launch, replace these with Chander Infra's own product photographs for stronger authenticity and SEO.
